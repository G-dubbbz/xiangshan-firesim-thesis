# Environment records

- `chipyard-baseline.md`: reproducible local Chipyard baseline and
  RocketConfig/Verilator validation result.
- `chipyard-parent-commit.txt`: exact Chipyard parent commit.
- `chipyard-submodules.txt`: recursive submodule revision snapshot.
- `chipyard-firesim-metasim-image.txt`: Docker image identity.
- `chipyard-local-container-compat.sha256`: integrity checksums for the
  local compatibility patch and its companion summary.
